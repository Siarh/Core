DPScope — локальный AI-компаньон через Ollama / Qwen
=======================================================

AI-компаньон работает на этом же ПК через локальный Ollama API
(http://localhost:11434). Внешний AI-сервис, OpenAI API и API-ключ не нужны.
По умолчанию используется установленная модель qwen3.5:27b; для менее
требовательного запуска можно выбрать qwen3.5:9b.

1. Проверка Ollama
------------------
Убедись, что Ollama запущена, затем в PowerShell:

  ollama list
  cd "...ModsAddonsDPScope	ools"
  python aou_ai_companion.py --check-ollama

Явная проверка модели 9B:

  python aou_ai_companion.py --check-ollama --model qwen3.5:9b

Если модель ещё не установлена, загрузи её один раз:

  ollama pull qwen3.5:27b

Или, для более лёгкого варианта:

  ollama pull qwen3.5:9b

2. Подготовка журнала боя из игры
---------------------------------
В игре выполни:

  /aou eventfile 1000 1

Экспорт намеренно разбит на страницы по 10 событий: массовая отправка
тысяч строк за один вызов перегружает игровой чат и может подвесить клиент.
Команда покажет номер страницы и диапазон строк. После снимков и OCR первой
страницы последовательно выполняй:

  /aou eventfile 1000 2
  /aou eventfile 1000 3
  ...

Повторяй до последней страницы. Все распознанные строки всех страниц добавь
в один обычный UTF-8 TXT-файл в исходном порядке. Каждая страница повторяет
одинаковый заголовок и BEGIN/END, а номера записей общие для всего экспорта:
ничего не удаляй между страницами и не перенумеровывай. Одинаковые повторные
строки допустимы, противоречащие дубликаты будут отмечены как ошибка.

Новый конвертер проверит, что присутствуют все страницы и все события, и
только после этого создаст профиль и запустит локальную Qwen. Открывать HTML-
конвертер отдельно не требуется. Для меньшей выгрузки вместо 1000 укажи
нужное число последних событий.

3. Полный анализ одной командой
--------------------------------
Из PowerShell в папке tools запусти:

  python aou_ai_companion.py "D:\Logs\aou_eventfile_ocr.txt"

Путь в кавычках замени на путь к своему TXT. В качестве результата рядом
с исходным файлом появится папка <имя_TXT>_DPScope со следующими файлами:

  AoU_combat_log.csv       восстановленный журнал;
  aou_event_profile.json   профиль событий для калькулятора;
  aou_report.json          детерминированный расчёт DPScope;
  aou_ai_payload.json      компактная сводка, переданная локальной модели;
  aou_ai_advice.md         ответ Qwen на русском языке.

По умолчанию используется qwen3.5:27b. Для меньшей модели:

  python aou_ai_companion.py "D:\Logs\aou_eventfile_ocr.txt" --model qwen3.5:9b

Если свободный бюджет очков отличается от 20, задай его явно, например:

  python aou_ai_companion.py "D:\Logs\aou_eventfile_ocr.txt" --budget 15

Коэффициент Решимости по умолчанию 0.015 — буквальное значение формулы,
которое использует текущий профиль импортера. Альтернативное 0.0015 можно
задать явно параметром --resolve-coefficient 0.0015; это другая трактовка,
а не автоматически подтверждённое значение.

4. Подготовка без запуска модели и повторный запуск
----------------------------------------------------
Чтобы проверить OCR и сформировать CSV/профиль/отчёт без Ollama:

  python aou_ai_companion.py "D:\Logs\aou_eventfile_ocr.txt" --prepare-only

Если программа сообщает о недостающей части блока, исправь OCR именно этой
строки и повтори команду. Неполный журнал не передаётся модели.

При повторном запуске в ту же папку добавь --overwrite. Эта опция заменяет
только выходные файлы анализа; исходный OCR-TXT и игровые записи не меняются.
Если TXT сохранён в Windows-1251, добавь --encoding cp1251.

5. Приватность и границы работы
-------------------------------
- Запрос к модели отправляется только локальному Ollama на этом ПК.
- OPENAI_API_KEY и другие облачные API-ключи не используются.
- В модель передаётся компактная сводка расчёта, а не сырой журнал событий;
  названия способностей и идентификаторы целей/игроков в AI payload не входят.
- Файл aou_ai_payload.json позволяет проверить, какие именно данные получила
  модель.
- Первичная загрузка модели через ollama pull требует интернет; после этого
  анализ выполняется локально.
- --prepare-only не обращается к модели.
- Lua-аддон Allods не запускает Python и не обращается к Ollama напрямую.
  Команды /aou ai on/off включают встроенного детерминированного советника
  в игре и не управляют отдельным desktop-компаньоном.
- Qwen объясняет результаты калькулятора и качество выборки. Её совет не
  является доказательством формул или игровым тестом в клиенте Allods.
