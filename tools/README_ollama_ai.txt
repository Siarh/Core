DPScope — локальный AI-компаньон через Ollama / Qwen
=======================================================

AI-компаньон работает на этом же ПК через локальный Ollama API
(http://localhost:11434). Внешний AI-сервис, OpenAI API и API-ключ не нужны.
По умолчанию используется qwen3.5:27b; можно выбрать qwen3.5:9b.

1. Проверка Ollama
------------------
Убедись, что Ollama запущена. Открой PowerShell в папке tools:

  cd "C:\Games\Allods Online\data\Mods\Addons\DPScope\tools"
  ollama list
  python aou_ai_companion.py --check-ollama

Путь в команде cd замени на фактический путь к папке DPScope\tools.

Если модель ещё не установлена, загрузи её один раз:

  ollama pull qwen3.5:27b

Для менее требовательного варианта:

  ollama pull qwen3.5:9b

2. Рекомендуемый способ: чтение журнала напрямую из user.cfg
-------------------------------------------------------------
DPScope сохраняет события в конфигурацию аддона. После полного закрытия игры
журнал находится в файле:

  <папка Allods Online>\data\Mods\Configs\DPScope\user.cfg

В старых конфигурациях также может использоваться Personal\user.cfg.
Извлекатель сначала ищет отдельный конфиг DPScope, а затем старый общий файл.

Закрой игру штатно, чтобы клиент успел записать user.cfg на диск. Затем в
PowerShell из папки tools выполни одну команду:

  python aou_extract_usercfg.py "C:\Games\Allods Online"

Замени путь на корневую папку своей игры. Можно передать и полный путь к файлу:

  python aou_extract_usercfg.py "C:\Games\Allods Online\data\Mods\Configs\DPScope\user.cfg"

Извлекатель работает только на чтение: не меняет, не очищает и не перезаписывает
user.cfg. Он извлекает aou_evt_count и aou_evt_1...aou_evt_N, проверяет наличие
всех записей и их структуру, создаёт локальную AOUCSV-выгрузку и запускает
обычный конвейер профиля/калькулятора/локальной Qwen.

Результаты появятся в папке:

  <папка Allods Online>\DPScope_UserCfg_Export\

Там будут исходный текстовый экспорт и подпапка analysis с файлами:

  AoU_combat_log.csv       восстановленный журнал;
  aou_event_profile.json   профиль событий;
  aou_report.json          детерминированный расчёт DPScope;
  aou_ai_payload.json      компактная сводка, переданная локальной модели;
  aou_ai_advice.md         ответ Qwen на русском языке.

Если нужно проверить чтение и построение профиля без запуска Ollama:

  python aou_extract_usercfg.py "C:\Games\Allods Online" --prepare-only

Если результаты уже существуют, добавь --overwrite. Это заменяет только
выходные файлы в DPScope_UserCfg_Export; исходный user.cfg не изменяется.

3. Резервный способ: OCR-экспорт из игрового чата
------------------------------------------------
Прямое чтение user.cfg предпочтительно. Если конфиг отсутствует или в нём нет
сохранённого журнала, можно использовать экспорт через чат:

  /aou eventfile 1000 1

Он разбит на страницы по 10 событий, чтобы не перегружать игровой клиент.
Сохрани каждую страницу скриншотами, распознай OCR и собери строки всех страниц
в один UTF-8 TXT. Затем запусти:

  python aou_ai_companion.py "D:\Logs\aou_eventfile_ocr.txt"

Повторные заголовки и BEGIN/END оставляй: конвертер сам соберёт общий журнал и
откажется анализировать выгрузку, если каких-либо записей не хватает.

4. Настройки анализа
--------------------
По умолчанию используется qwen3.5:27b. Для меньшей модели:

  python aou_extract_usercfg.py "C:\Games\Allods Online" --model qwen3.5:9b

Если бюджет свободных очков отличается от 20, укажи его явно:

  python aou_extract_usercfg.py "C:\Games\Allods Online" --budget 15

Коэффициент Решимости по умолчанию 0.015 — буквальное значение формулы,
которое использует текущий профиль импортера. Альтернативное 0.0015 можно
задать параметром --resolve-coefficient 0.0015; это другая трактовка, а не
автоматически подтверждённое значение.

5. Приватность и границы работы
-------------------------------
- Запрос к модели отправляется только локальному Ollama на этом ПК.
- OPENAI_API_KEY и другие облачные API-ключи не используются.
- В модель передаётся компактная сводка расчёта, без сырых строк журнала,
  названий способностей и идентификаторов целей/игроков.
- aou_ai_payload.json позволяет проверить, какие именно данные получила модель.
- Первичная загрузка через ollama pull требует интернет; после этого анализ
  выполняется локально.
- Lua-аддон Allods не запускает Python и не обращается к Ollama напрямую.
  Встроенная команда /aou ai on/off управляет только игровым детерминированным
  советником, а не отдельным desktop-компаньоном.
- Вывод Qwen объясняет результаты калькулятора и качество выборки; это не
  доказательство игровых формул и не замена проверке в клиенте Allods.
