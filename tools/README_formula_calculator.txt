DPScope Formula Engine
=====================

Установка
---------
Файл aou_formula_calculator.py — отдельный калькулятор по формулам сервера.
Он не заменяет существующие Lua-формулы интерфейса DPScope.

Запуск
------
В папке tools:

python .\aou_formula_calculator.py .\aou_profile_template.json

Сохранить отчёт:
python .\aou_formula_calculator.py .\profile.json --out .\report.json

Данные
------
Каждый sample — событие с:
second     — секунда боя;
raw        — исходная величина урона или лечения до множителей;
target_hp  — здоровье цели/союзника в долях от 0 до 1;
target_resistance — сопротивление цели R (10 — нейтрально);
block_fraction / parry_fraction — доли снижения урона 0..1.

Решимость
---------
resolve_gain_divisor=2.4 — предварительная калибровка по трём тестам.
resolve_coefficient=0.0015 соответствует пояснению: 1.5% за 10 единиц шкалы
при 1000 единицах Решимости.
В исходной записи также присутствует 0.015. Для проверки можно заменить
значение на 0.015 в JSON.

Рекомендации
------------
Укажи allocation_budget — число свободных очков для распределения.
Калькулятор отдельно оптимизирует каждую активность и каждый режим DPS/HPS.
Используется жадное распределение очков, это приближённый поиск.

Ограничения
-----------
1. Три агрегированные записи user.cfg нельзя автоматически превратить в
   полноценный событийный журнал.
2. Для точного Resolve нужны события и их время.
3. Поглощение рунами пока не реализовано: формулы рунического поглощения
   в исходных данных отсутствуют.
4. Сопротивления, блок и парирование принимаются готовыми значениями событий.
5. Неопределённость влияния Могущества на лечение вынесена в настройку
   might_affects_healing.
6. Модель не утверждает, что серверная реализация проверена игровыми тестами.
